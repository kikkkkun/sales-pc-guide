# 営業職におすすめのPC設定

**移動時間を、タスクが進む時間に。**

Windows 11のふた・スリープ・Wi-Fi設定を、画面操作中心に紹介する日本語の記事です。実際に改善した事例、動作確認、変更前の設定への戻し方をまとめています。

記事URL（GitHub Pages）: https://kikkkkun.github.io/sales-pc-guide/

## ファイル

- `index.html`：CSS・JavaScriptを含む記事本体。外部ライブラリ・広告・アクセス解析は使用していません。
- `.nojekyll`：GitHub Pagesで静的ファイルをそのまま配信するためのファイル。

## ローカルで読む

`index.html`をブラウザーで開くと記事を読めます。コピー機能はHTTPSまたはlocalhostで利用できます。利用できない場合はコマンドを手動でコピーできます。JavaScriptが無効でも本文・目次・折りたたみ手順を読めます。

右上の「ダーク／ライト」で表示を切り替えられます。初回は端末のテーマに合わせ、選択後は同じブラウザー・公開先で表示の好みを保存します。ブラウザーの保存が制限されている場合も、その画面内での切り替えはできます。JavaScriptが無効の場合は端末のテーマに合わせて表示します。印刷時は白背景になります。

## 公開方法

GitHubの **Settings → Pages → Build and deployment** で、**Deploy from a branch / main / (root)** を選びます。

## 内容について

今回の改善事例を一般向けに整理したもので、機種ごとの動作や通信の継続を保証するものではありません。設定変更前の値を控え、電源・通信・放熱を確保して確認してください。参考にしたMicrosoft・Dellの公式情報は記事末尾に記載しています。
