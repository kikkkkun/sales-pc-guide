# 営業職におすすめのPC設定

**移動時間を、タスクが進む時間に。**

Windows 11のふた・スリープ・Wi-Fi設定を、PowerShellの一括設定と画面操作で紹介する日本語の記事です。実際に改善した事例、動作確認、変更前の設定への戻し方をまとめています。
一括設定は元の電源プランを残したまま複製し、値を検証してから「Sales PC Guide」プランへ切り替えます。バッテリー時の画面消灯を止める追加対策は任意です。復元コマンドは同じWindowsユーザーのローカル復元記録を読み、元のプランへ切り替えます。
Windows 11 25H2で撮影した5枚の実際のスクリーンショットを6箇所に掲載し、番号・枠と説明で操作箇所を示しています。必要な範囲を切り抜き、設定値や項目名は書き換えていません。Wi-Fiの省電力設定が表示されない実例も掲載しています。

記事URL（GitHub Pages）: https://kikkkkun.github.io/sales-pc-guide/

## ファイル

- `index.html`：CSS・JavaScriptを含む記事本体。外部ライブラリ・広告・アクセス解析は使用していません。
- `.nojekyll`：GitHub Pagesで静的ファイルをそのまま配信するためのファイル。

## ローカルで読む

`index.html`をブラウザーで開くと記事を読めます。コピー機能はHTTPSまたはlocalhostで利用できます。利用できない場合はコマンドを手動でコピーできます。JavaScriptが無効でも本文・目次・折りたたみ手順を読めます。

右上の「ダーク／ライト」で表示を切り替えられます。初回は端末のテーマに合わせ、選択後は同じブラウザー・公開先で表示の好みを保存します。ブラウザーの保存が制限されている場合も、その画面内での切り替えはできます。JavaScriptが無効の場合は端末のテーマに合わせて表示します。印刷時は白背景になります。
図の「拡大して見る」から、縦横にスクロールできる拡大表示を開けます。「閉じる」またはEscキーで閉じ、キーボード操作では元のボタンへ戻ります。スクリーンショットのPNG／JPEGをHTML内のSVGに埋め込み、番号と枠を重ねています。画像は外部から読み込まず、JavaScriptが無効でも本文と図は表示されます。撮影時のテーマを保ち、記事のライト／ダーク切り替えでは画像を反転しません。画像内の設定項目は操作できません。

## 公開方法

GitHubの **Settings → Pages → Build and deployment** で、**Deploy from a branch / main / (root)** を選びます。

## 内容について

今回の改善事例を一般向けに整理したもので、機種ごとの動作や通信の継続を保証するものではありません。設定変更前の値を控え、電源・通信・放熱を確保して確認してください。参考にしたMicrosoft・Dellの公式情報は記事末尾に記載しています。

一括設定・復元コードはPowerShell 5.1と7で構文・模擬テストを確認しています。記事更新時にPC本体の設定を変更して試験したものではありません。会社の管理や機種により適用できない場合は、エラーの案内に従ってください。
