01 / USE THE TIME

「待っている時間」を、
次の仕事の準備に。

資料の下調べ、AIによる下書き、時間のかかる集計。処理の完了を待つ間に移動できれば、到着後は結果の確認から始められます。

ただし、ふたを閉じたときのスリープやWi-Fiの省電力設定が、処理や通信の中断につながることがあります。まずは、自分が使うツールの動き方を確認しましょう。

ON YOUR PC

PC上で動く処理

Excelの集計やローカルの自動処理など。PCがスリープすると処理も中断するため、必要な間は起動状態を保ちます。

クラウド側で動く処理

依頼後にサーバー側で続く処理は、PCを起動し続ける必要がない場合も。画面を閉じた後の動作は、ツールごとに確認します。

「AIに頼んだら必ず動き続ける」とは限りません。

ブラウザーの接続が必要な処理や、途中で操作を求めるツールもあります。最初は短い処理で、ふたを閉じた後も進むか試しておきましょう。

02 / BEFORE YOU START

電源の設定と、
通信の準備はセットで。

  • 移動先でも使える通信回線を用意する

    インターネットが必要な処理には、スマートフォンのテザリングやモバイルルーターなどを使います。会社のWi-Fiの圏外へ出れば、その接続は切れます。圏外や回線切り替えによる中断までは、この設定では防げません。

  • バッテリー残量と、処理にかかる時間を確認する

    スリープを止めたり、Wi-Fiを最大パフォーマンスにしたりすると、消費電力は増えます。PCだけでなく、テザリング側の電池残量や通信量も確認します。

  • 変更前の値を、画面写真やメモに残す

    電源接続時とバッテリー使用時の両方を控えます。会社の管理で項目が変更できない場合は、管理担当者に確認してください。

手提げやエコバッグでも、放熱の確認を。

布の通気性だけでは、PCの吸排気口が塞がれないとは限りません。布や書類が触れて通風を妨げる状態、熱がこもる収納状態で稼働を続けないでください。通風を確保できない持ち運びでは、処理を区切って休止状態またはシャットダウンにします。

まずは机などの硬く平らな場所で動作を確認し、使用機種の取り扱い説明に従ってください。Dellの取り扱い説明（英語PDF）

03 / SET UP WINDOWS

3つの基本設定を、
まとめて。

電源接続時だけでなく、バッテリー使用時の欄も確認します。すでに下記の値なら、変更は不要です。設定前に、それぞれの元の値を控えてください。

POWERSHELL · QUICK SETUP

コピーして、まとめて設定。

基本の3項目を、一括で設定できます。現在の電源プランを複製して作業用プランを作るため、元のプランは残ります。

  • ふたを閉じたとき：何もしない
  • 自動スリープ：なし
  • Wi-Fiの省電力：最大パフォーマンス

上の3項目は、電源接続時・バッテリー使用時の両方に設定します。

  1. スタートで「Windows PowerShell」を検索し、「管理者として実行」で開きます。会社のPCで権限や設定が制限されている場合は、管理担当者に確認してください。
  2. 下のコマンド全文で内容を確認してからコピーし、PowerShellに貼り付けてEnterを押します。
  3. 画面消灯の追加対策を聞かれたら、通常はNまたはそのままEnter。今回の改善事例と同じく、バッテリー時の画面消灯も止めて試す場合だけYを入力します。
  4. 完了メッセージを確認し、10分以上の動作確認へ進みます。元に戻すときは、下の復元用コマンドを使います。

一括設定コマンドの全文を確認する
& {
  $ErrorActionPreference = 'Stop'
  function Invoke-Power([string[]]$PowerArgs) {
    $result = & powercfg.exe @PowerArgs 2>&1
    if ($LASTEXITCODE -ne 0) { throw "powercfg に失敗しました: $($PowerArgs -join ' ')`n$($result -join "`n")" }
    $result -join "`n"
  }
  function Get-ActivePlan {
    $text = Invoke-Power -PowerArgs @('/getactivescheme')
    $match = [regex]::Match($text, '(?i)\b[0-9a-f]{8}(?:-[0-9a-f]{4}){3}-[0-9a-f]{12}\b')
    if (-not $match.Success) { throw '現在の電源プランを確認できません。' }
    $match.Value
  }
  function Get-SettingValues($plan, $group, $setting) {
    $text = Invoke-Power -PowerArgs @('/qh', $plan, $group, $setting)
    $values = [regex]::Matches($text, '(?i)0x([0-9a-f]{8})')
    if ($values.Count -lt 2) { throw "設定を読み取れません: $setting" }
    [Convert]::ToUInt32($values[$values.Count - 2].Groups[1].Value, 16)
    [Convert]::ToUInt32($values[$values.Count - 1].Groups[1].Value, 16)
  }
  $stateDir = Join-Path $env:LOCALAPPDATA 'SalesPcGuide'
  $statePath = Join-Path $stateDir 'restore.json'
  $originalPlan = $null
  $guidePlan = $null
  $duplicateAttempted = $false
  try {
    if (Test-Path -LiteralPath $statePath) { throw '復元情報が既にあります。先に記事の「元に戻す」コマンドを実行してください。' }
    Write-Host '元の電源プランと、設定できる項目を確認します。'
    $originalPlan = Get-ActivePlan
    $guidePlan = [guid]::NewGuid().ToString()
    $settings = @(
      @('SUB_BUTTONS', 'LIDACTION'),
      @('SUB_SLEEP', 'STANDBYIDLE'),
      @('19cbb8fa-5279-450e-9fac-8a3d5fedd0c1', '12bbebe6-58d6-4636-95bb-3217ef867c1a')
    )
    foreach ($item in $settings) { $null = Get-SettingValues $originalPlan $item[0] $item[1] }
    $displayOff = (Read-Host '追加対策：バッテリー時の自動画面消灯も「なし」にしますか？ y＝変更、Enter＝変更しない [y/N]') -match '^[yY]$'
    if ($displayOff) { $null = Get-SettingValues $originalPlan 'SUB_VIDEO' 'VIDEOIDLE' }
    $null = New-Item -ItemType Directory -Path $stateDir -Force
    $state = [ordered]@{ version = 1; originalPlan = $originalPlan; guidePlan = $guidePlan; createdAt = (Get-Date).ToString('o'); displayOffOnBattery = $displayOff }
    $bytes = [Text.Encoding]::UTF8.GetBytes(($state | ConvertTo-Json))
    $stream = [IO.File]::Open($statePath, [IO.FileMode]::CreateNew, [IO.FileAccess]::Write, [IO.FileShare]::None)
    try { $stream.Write($bytes, 0, $bytes.Length) } finally { $stream.Dispose() }
    $saved = Get-Content -LiteralPath $statePath -Raw -Encoding UTF8 | ConvertFrom-Json
    if ($saved.originalPlan -ne $originalPlan -or $saved.guidePlan -ne $guidePlan) { throw '復元情報の保存を確認できません。' }
    Write-Host "復元情報を保存しました: $statePath"
    Write-Host '元のプランを残し、専用プランに設定します。'
    $duplicateAttempted = $true
    $null = Invoke-Power -PowerArgs @('/duplicatescheme', $originalPlan, $guidePlan)
    $null = Invoke-Power -PowerArgs @('/changename', $guidePlan, 'Sales PC Guide')
    foreach ($item in $settings) {
      $null = Invoke-Power -PowerArgs @('/setacvalueindex', $guidePlan, $item[0], $item[1], '0')
      $null = Invoke-Power -PowerArgs @('/setdcvalueindex', $guidePlan, $item[0], $item[1], '0')
      $values = @(Get-SettingValues $guidePlan $item[0] $item[1])
      if ($values[0] -ne 0 -or $values[1] -ne 0) { throw "設定値が一致しません: $($item[1])" }
    }
    if ($displayOff) {
      $null = Invoke-Power -PowerArgs @('/setdcvalueindex', $guidePlan, 'SUB_VIDEO', 'VIDEOIDLE', '0')
      $values = @(Get-SettingValues $guidePlan 'SUB_VIDEO' 'VIDEOIDLE')
      if ($values[1] -ne 0) { throw '画面消灯の設定値が一致しません。' }
    }
    Write-Host '設定値を確認できました。専用プランへ切り替えます。'
    $null = Invoke-Power -PowerArgs @('/setactive', $guidePlan)
    if ((Get-ActivePlan) -ne $guidePlan) { throw '専用プランへの切り替えを確認できません。' }
    foreach ($item in $settings) {
      $values = @(Get-SettingValues $guidePlan $item[0] $item[1])
      if ($values[0] -ne 0 -or $values[1] -ne 0) { throw '切り替え後の設定値が一致しません。' }
    }
    if ($displayOff -and (@(Get-SettingValues $guidePlan 'SUB_VIDEO' 'VIDEOIDLE'))[1] -ne 0) { throw '切り替え後の画面消灯の設定値が一致しません。' }
    Write-Host '完了：ふた＝何もしない、スリープ＝なし、Wi-Fi＝最大パフォーマンス（電源接続時・バッテリー時）。'
    if ($displayOff) { Write-Host '追加対策：バッテリー時の自動画面消灯も「なし」にしました。' }
    Write-Host '記事の動作確認を行ってください。元に戻すときは復元用コマンドを使います。'
  } catch {
    $failure = $_
    if ($originalPlan) {
      try {
        if ((Get-ActivePlan) -ne $originalPlan) { $null = Invoke-Power -PowerArgs @('/setactive', $originalPlan) }
        if ((Get-ActivePlan) -ne $originalPlan) { throw '元のプランを確認できません。' }
        Write-Host '元の電源プランで動作していることを確認しました。元のプランの設定値は変更していません。'
      } catch { Write-Warning "元のプランへの復帰を確認できません。コントロール パネルで確認してください。復元情報: $statePath" }
    }
    if ($duplicateAttempted) { Write-Warning '専用プランが残っている場合があります。自動削除はしていません。' }
    if (Test-Path -LiteralPath $statePath) { Write-Host "再実行の前に復元用コマンドを実行してください。復元情報: $statePath" }
    throw $failure
  }
}

復元情報は、このPCのローカルアプリデータ内の「SalesPcGuide」フォルダーに保存します。復元前に同じコマンドを再実行した場合は、情報を上書きせず停止します。エラーが出たら続けず、表示された案内を確認してください。

作業用プラン名は「Sales PC Guide」です。このコマンドは電源プラン設定と、このPC内の復元記録だけを扱います。復元時も、設定時と同じWindowsユーザーで実行してください。

スリープを止め、Wi-Fiを最大パフォーマンスにすると電池消費が増えます。吸排気口を塞がず、熱がこもる収納状態では動かさないでください。通信や処理が続くかは実際に確認します。

画面から設定する場合

一括コマンドで設定した方は、下の操作を重ねて行う必要はありません。画面で確認したい場合や、項目ごとに設定したい場合の手順です。

実際のWindows画面と見比べながら設定できます。
Windows 11 25H2で撮影したスクリーンショットです。必要な部分を切り抜き、操作箇所に番号と枠を重ねています。設定値や項目名は書き換えていません。画面の明暗は撮影時のテーマを保ち、記事のテーマを切り替えても反転しません。Windowsの版や機種で、表示名・配置・項目の有無は異なります。

01

ふたを閉じても、処理を続ける

カバーを閉じたときの動作

  1. スタートで「コントロール パネル」を検索して開きます。
  2. 「ハードウェアとサウンド」→「電源オプション」→「カバーを閉じたときの動作の選択」を開きます。
  3. 「カバーを閉じたときの動作」を、バッテリー駆動・電源に接続の両方で「何もしない」にし、「変更の保存」を押します。
バッテリー駆動 ／ 電源に接続何もしない

一覧表示のコントロール パネルでは「電源オプション」を直接開けます。電源ボタンの動作や、サインイン・画面ロックの設定は変更しません。

02

自動スリープで、中断させない

操作しない時間が続いたときの動作

  1. 「設定」→「システム」→「電源とバッテリー」を開きます。
  2. 「画面、スリープ、休止状態のタイムアウト」または「画面とスリープ」を開きます。
  3. 「デバイスをスリープ状態にする」時間を、バッテリー使用時・電源接続時の両方で「なし」にします。
バッテリー使用時 ／ 電源接続時スリープまでの時間：なし

設定画面の名称はバージョンで異なります。コントロール パネルの「電源オプション」→選択中のプランの「プラン設定の変更」でも、スリープまでの時間を確認できます。

03

Wi-Fiの省電力を、見直す

無線接続が切れる場合の対策

  1. コントロール パネルの「電源オプション」で、選択中のプランの「プラン設定の変更」を開きます。
  2. 「詳細な電源設定の変更」を開きます。表示される場合は「ワイヤレス アダプターの設定」→「省電力モード」へ進みます。
  3. バッテリ駆動・電源に接続の両方を「最大パフォーマンス」にし、「適用」→「OK」を押します。
バッテリ駆動 ／ 電源に接続最大パフォーマンス

Wi-Fiが頻繁に切れる場合の対処として、Microsoftも案内している設定です。

「ワイヤレス アダプターの設定」が表示されない場合

Windows標準のPowerShellから同じ設定を確認・変更できます。スタートで「PowerShell」を検索して開き、次の順で実行してください。各ブロックは貼り付けた後にEnterを押します。エラーやアクセス拒否が出たら、そこで止めて管理担当者に確認してください。

① 現在の設定を確認する（変更しません）

PowerShell · 確認
powercfg /getactivescheme
powercfg /qh SCHEME_CURRENT 19cbb8fa-5279-450e-9fac-8a3d5fedd0c1

プラン名と「現在のAC／DC電源設定のインデックス」を両方控えてください。 ACは電源接続時、DCはバッテリー時です。該当項目が出ない場合は、以降を実行しないでください。

末尾の値：0＝最大パフォーマンス ／ 1＝省電力（低） ／ 2＝省電力（中） ／ 3＝省電力（高）。例：0x00000002 は「2」です。

② Wi-Fiを最大パフォーマンスにする

PowerShell · 変更
& {
  powercfg /setacvalueindex SCHEME_CURRENT 19cbb8fa-5279-450e-9fac-8a3d5fedd0c1 12bbebe6-58d6-4636-95bb-3217ef867c1a 0
  if ($LASTEXITCODE -ne 0) { throw '電源接続時の変更に失敗しました。ここで止めてください。' }
  powercfg /setdcvalueindex SCHEME_CURRENT 19cbb8fa-5279-450e-9fac-8a3d5fedd0c1 12bbebe6-58d6-4636-95bb-3217ef867c1a 0
  if ($LASTEXITCODE -ne 0) { throw 'バッテリー時の変更に失敗しました。AC側は変更済みの場合があります。' }
  powercfg /setactive SCHEME_CURRENT
  if ($LASTEXITCODE -ne 0) { throw '設定の適用に失敗しました。' }
  powercfg /qh SCHEME_CURRENT 19cbb8fa-5279-450e-9fac-8a3d5fedd0c1
}

対象は現在選択している電源プランのWi-Fi設定だけです。完了後、AC・DCの両方が 0x00000000 になったことを確認してください。ふたやスリープの設定は、上の画面操作で別途行います。

「スリープしない」は、必要な間だけ。

作業が終わったら元の設定に戻すか、スタートの電源メニューから休止状態・シャットダウンを選びます。設定変更後は、ふたを閉じるだけではPCは眠りません。

WHAT WE LEARNED

ふたの設定だけでなく、
バッテリー時の省電力設定も確認する。

2026年9月25日 · 今回の改善事例から

追加で試した「自動画面消灯：なし」

「設定」→「システム」→「電源とバッテリー」から、画面・スリープのタイムアウトを開きます。バッテリー使用時に画面をオフにする時間を「なし」に変更しました。

今回は2項目を同時に変更しているため、どちらが効いたかは単独で切り分けていません。画面消灯を止めることが、すべてのPCで必要とは限りません。試す場合は元の時間を控え、改善しなければ戻してください。

画面が消えることと、スリープは別の設定です。

一部のPCは、画面消灯後の省電力動作が機種やWindowsの仕様に左右されます。「画面を消したら必ずWi-Fiが切れる」という意味ではありません。

05 / CHECK & RESTORE

小さく試してから、
いつもの使い方へ。

まずは安定した通信と放熱を確保できる場所で確認します。電源接続時・バッテリー時の両方で同じ確認をしてください。

チェックはこの画面上だけの確認用です。再読み込み後の保存はしません。

一括コマンドで設定した場合の戻し方

一括設定時の記録を自動で読み込み、元の電源プランへ切り替えます。設定時と同じWindowsユーザーでWindows PowerShellを管理者として開き、内容を確認してから以下をコピーし、貼り付けてEnterを押してください。

復元用コマンドの全文を確認する
& {
  $ErrorActionPreference = 'Stop'
  function Invoke-Power([string[]]$PowerArgs) {
    $result = & powercfg.exe @PowerArgs 2>&1
    if ($LASTEXITCODE -ne 0) { throw "powercfg に失敗しました: $($PowerArgs -join ' ')`n$($result -join "`n")" }
    $result -join "`n"
  }
  function Get-ActivePlan {
    $text = Invoke-Power -PowerArgs @('/getactivescheme')
    $match = [regex]::Match($text, '(?i)\b[0-9a-f]{8}(?:-[0-9a-f]{4}){3}-[0-9a-f]{12}\b')
    if (-not $match.Success) { throw '現在の電源プランを確認できません。' }
    $match.Value
  }
  $stateDir = Join-Path $env:LOCALAPPDATA 'SalesPcGuide'
  $statePath = Join-Path $stateDir 'restore.json'
  $originalPlan = $null
  try {
    if (-not (Test-Path -LiteralPath $statePath)) { throw '復元情報がありません。この一括設定を実行したWindowsユーザーで確認してください。' }
    $saved = Get-Content -LiteralPath $statePath -Raw -Encoding UTF8 | ConvertFrom-Json
    $originalId = [guid]::Empty
    $guideId = [guid]::Empty
    if ($saved.version -ne 1 -or -not [guid]::TryParse([string]$saved.originalPlan, [ref]$originalId) -or -not [guid]::TryParse([string]$saved.guidePlan, [ref]$guideId) -or $originalId -eq [guid]::Empty -or $guideId -eq [guid]::Empty -or $originalId -eq $guideId) { throw '復元情報の形式を確認できません。ファイルを変更せず管理担当者に確認してください。' }
    $originalPlan = $originalId.ToString()
    Write-Host '記録した元の電源プランへ戻します。'
    $null = Invoke-Power -PowerArgs @('/setactive', $originalPlan)
    if ((Get-ActivePlan) -ne $originalPlan) { throw '元のプランへの切り替えを確認できません。' }
    $historyPath = Join-Path $stateDir ('history-' + (Get-Date -Format 'yyyyMMdd-HHmmss') + '-' + [guid]::NewGuid().ToString('N') + '.json')
    Move-Item -LiteralPath $statePath -Destination $historyPath
    Write-Host '元の電源プランへの復帰を確認しました。専用プランは削除せず残しています。'
    Write-Host "復元記録: $historyPath"
  } catch {
    $failure = $_
    if ($originalPlan) {
      try {
        if ((Get-ActivePlan) -ne $originalPlan) { $null = Invoke-Power -PowerArgs @('/setactive', $originalPlan) }
        if ((Get-ActivePlan) -ne $originalPlan) { throw '元のプランを確認できません。' }
        Write-Host '元の電源プランで動作していることを確認しました。'
      } catch { Write-Warning '元のプランへの復帰を確認できません。コントロール パネルで確認してください。' }
    }
    if (Test-Path -LiteralPath $statePath) { Write-Warning "復元処理は完了していません。復元情報を残しています: $statePath" }
    throw $failure
  }
}

作業用プランは削除せず残します。復元に成功した記録も履歴として保存します。この復元方法は、上の「一括設定コマンド」を使った場合のものです。画面操作や項目別コマンドで変更した場合は、下の方法で元の値に戻してください。

画面操作・項目別コマンドで設定した場合

設定したのと同じ画面を開き、変更前に控えた値に戻します。ふたの動作とWi-Fiは保存・適用まで行い、電源接続時・バッテリー時をそれぞれ見直してください。

一律の「既定値に戻す」では、今回触っていない項目まで変わる場合があります。変更した項目だけを戻しましょう。

コマンドで変更したWi-Fi設定を戻す場合

コントロール パネルの「電源オプション」で、変更前に控えたプランと同じものを選んでから実行します。AC・DCそれぞれの元の値（0～3）を聞かれたら入力します。記録がない場合は値を推測せず、管理担当者に確認してください。

PowerShell · 復元
& {
  $acValue = Read-Host '記録した変更前のAC値を入力（0～3）'
  $dcValue = Read-Host '記録した変更前のDC値を入力（0～3）'
  if ($acValue -notmatch '^[0-3]$' -or $dcValue -notmatch '^[0-3]$') {
    throw '0～3の数字で入力してください。設定は変更していません。'
  }
  powercfg /setacvalueindex SCHEME_CURRENT 19cbb8fa-5279-450e-9fac-8a3d5fedd0c1 12bbebe6-58d6-4636-95bb-3217ef867c1a $acValue
  if ($LASTEXITCODE -ne 0) { throw 'AC側の復元に失敗しました。' }
  powercfg /setdcvalueindex SCHEME_CURRENT 19cbb8fa-5279-450e-9fac-8a3d5fedd0c1 12bbebe6-58d6-4636-95bb-3217ef867c1a $dcValue
  if ($LASTEXITCODE -ne 0) { throw 'DC側の復元に失敗しました。AC側は復元済みの場合があります。' }
  powercfg /setactive SCHEME_CURRENT
  if ($LASTEXITCODE -ne 0) { throw '復元した設定の適用に失敗しました。' }
  powercfg /qh SCHEME_CURRENT 19cbb8fa-5279-450e-9fac-8a3d5fedd0c1
}

最後に表示されるAC・DC値が、控えた値と一致することを確認します。このコマンドはWi-Fi設定だけを戻します。スリープや画面消灯は、元の画面から戻してください。

まだ切れる場合は、起きた時刻と条件を記録する。

電源接続の有無、使った回線、ふたを閉じて何分で止まったかを控えます。回線・ドライバー・会社のポリシーなど、別の原因の可能性もあるため、同じ設定変更を繰り返すより切り分けに役立ちます。
